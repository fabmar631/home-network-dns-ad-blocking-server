# Project screenshots

The images in this folder are sanitized copies of project photos and screenshots. The original files were left unchanged and are not part of this repository.

| Image | What it documents |
| --- | --- |
| `server-and-router.png` | Lenovo ThinkCentre server and Vodafone Power Hub; identification labels are blurred. |
| `adguard-dashboard-initial.png` | Initial dashboard snapshot: 827 queries, 352 blocked, 43%, and 4 ms average processing time. Client identities are blurred. |
| `adguard-blocklists-enabled.png` | AdGuard DNS Filter and HaGeZi Multi Normal shown enabled. Browser tab titles are blurred. |
| `router-dns-configuration.png` | Vodafone Power Hub DNS settings pointed at the AdGuard server. Terminal output above the display is fully obscured. |

The screenshots retain only local addresses already recorded in the project documentation. Credentials, Wi-Fi details, MAC addresses, serial labels, public IP addresses, and device identities visible in source images were obscured or excluded. The initial dashboard figures are a point-in-time record, not a long-term performance claim.
